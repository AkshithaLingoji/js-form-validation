# Login & Signup Form Validation

A responsive Login and Signup form built using **HTML, CSS, and JavaScript**, with client-side form validation and clean UI design.

## 🔹 Features
- Signup and Login forms
- Client-side form validation using JavaScript
- Error handling with visual feedback
- Responsive design for different screen sizes
- Custom UI with icons and smooth transitions

## 🔹 Technologies Used
- HTML5
- CSS3 (Flexbox, Media Queries)
- JavaScript (DOM Manipulation, Event Handling)

## 🔹 Validation Rules
- All fields are required
- Email format validation
- Password must be at least 8 characters
- Password and Repeat Password must match

## 🔹 What I Learned
- How form submission works in JavaScript
- Using `addEventListener` and `preventDefault()`
- DOM traversal (`parentElement`, `classList`)
- Writing reusable validation functions
- Making layouts responsive using media queries
